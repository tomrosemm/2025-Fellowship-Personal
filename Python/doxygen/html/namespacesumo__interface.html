steps,
print_data = True,
collect_data = None,

Run a SUMO simulation for a specified number of steps and collect vehicle data, with flexible options.

Parameters
traciTraCI module instance with an active connection
stepsNumber of simulation steps to run
print_dataIf True, print simulation data to screen.
collect_dataList of data types to collect (e.g. ["position", "speed", "color"])
step_delayTime in seconds to wait between steps
vehicle_callbacksDictionary of callback functions to execute on vehicles
Returns
List of dictionaries containing simulation data for each step

Steps:

  1. Advances the simulation by the specified number of steps
  2. Collects data for each vehicle at each step, including position, speed, color, lane, and lane position
  3. Executes any specified callback functions for each vehicle at each step
  4. Optionally prints the collected data to the screen
  5. Waits for the specified delay between steps
