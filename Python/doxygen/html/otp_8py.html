Detailed Description

Provides a function to generate a one-time password (OTP) using a secret and the current timestamp. Used by vehicle and authentication modules to create time-based OTPs for secure authentication workflows.

Author
Tom Rose
  • Concatenates the provided secret with the current Unix timestamp.
  • Hashes the result using SHA-256 to produce a unique OTP for each time interval.
  • Returns both the OTP and the timestamp used for generation.
